# Bank Loan Report Project

## 📌 Overview
This project provides a comprehensive analysis of bank loan data through structured cleaning, detailed analysis, and interactive dashboards. It is designed to highlight loan performance, borrower characteristics, and financial trends for better decision-making.

## 🎯 Objectives
- Clean and prepare raw loan datasets for accurate analysis.
- Perform data analysis to uncover trends in loan applications, funding, and repayments.
- Build dashboards that summarize and visualize key performance indicators (KPIs).

## 🛠️ Key Components
### 1. Data Cleaning
- Removal of duplicates and inconsistencies
- Handling missing values
- Structuring datasets for analysis

### 2. Data Analysis
- Segmentation of loans into good vs. bad categories
- Identification of repayment trends
- Breakdown by loan purpose, grade, and borrower attributes

### 3. Dashboards
- **Summary Dashboard**  
  Provides high-level KPIs including:
  - Total loan applications, funding, and amount received
  - Average interest rate and debt-to-income ratio
  - Good vs. bad loan distribution
  - Loan status breakdown (Fully Paid, Charged Off, Current)

## 📊 Insights
- **Good Loans**: 86.18% of applications funded, with strong repayment performance.  
- **Bad Loans**: 13.82% of applications, highlighting risk areas.  
- **Loan Purpose**: Debt consolidation dominates applications, followed by car and home improvement.  
- **Borrower Profile**: Majority of applicants are renters or mortgage holders, with varied employment lengths.
