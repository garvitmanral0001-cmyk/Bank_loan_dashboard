# Bank Loan Report Dashboard

## 📌 Overview
This project presents a comprehensive financial dashboard built in Microsoft Excel to analyze and visualize loan performance. It highlights key metrics such as loan applications, funding amounts, interest rates, and debt-to-income ratios. The dashboard provides both summary and detailed views to support financial decision-making.

## 🎯 Objectives
- Transform raw loan data into structured, cleaned datasets.
- Perform data analysis to identify trends in loan performance.
- Provide a **Summary Dashboard** for quick insights into KPIs.
- Deliver an **Overview Dashboard** with detailed breakdowns of loan categories, grades, and purposes.

## 🛠️ Key Features
- **Data Cleaning**: Removal of inconsistencies, duplicates, and missing values.
- **Data Analysis**: Identification of good vs. bad loans, repayment trends, and funding distribution.
- **Summary Dashboard**: High-level metrics including total applications, funding, amount received, average interest rate, and DTI.
- **Overview Dashboard**: Detailed breakdown of loan applications by status (Fully Paid, Charged Off, Current), grade, and purpose.

## 📊 Insights from Dashboard
- **Good Loan Issued**: 86.18% of total applications, with $370.2M funded and $435.8M received.
- **Bad Loan Issued**: 13.82% of total applications, with $65.5M funded and $37.3M received.
- **Loan Breakdown**: Fully paid loans dominate, while charged-off loans highlight risk areas.
- **KPIs**: Average interest rate of 12.05% and average DTI of 13.33%.
